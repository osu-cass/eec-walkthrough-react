\section{Introduction}
This document describes all of the API endpoints for the EEC Walkthrough application.
The document is organized by route name and each API endpoint includes a general description, the expected input, and  the expected output.

This API uses cookies to keep track of the user who is making requests. This means that each of these endpoints will have access to all user information for the current user even if it is not requested in the body. This includes ID, username, first name, last name, email, and their role. All endpoints also have the option to return an error code. This will have a status code between 400 and 500. In the case of a validation error an object with the property "errors" will be returned, which is an array of objects that describe what was wrong with the request body. All other errors will return an object with the property "error", which is a string that describes the error.

To make handling responses from the API easier, all responses return a JSON object. To make it easier to tell what requests are being made to the API (as apposed to requests to get files), each API request starts with "api".

\section{API Endpoints}

\subsection{Card Endpoints}

\noindent
\textbf{\textcolor{Green}{POST} api/cards} \\
Creates a new card. Only editors and admins can use this endpoint.
\begin{itemize}
    \item HeaderId: The ID of the header that this card belongs to.
    \item cardType: The type of card to create. Examples include: default card, internal card, thumbnail gallery, internal thumbnail gallery, and more.
    \item title: The title of the card.
    \item items: The items that will be included in the card.
    \begin{itemize}
        \item cardId: The ID of the card that this item belongs to.
        \item indentation: The level of indentation (0 is none, 3 is max).
        \item iconType: The ID of the icon that is displayed at the start of the item.
        \item contentText: The main body of text for the item.
        \item contentUrl: The URL of the item. For graphic items this will be the URL of the image to display, for link items this will be the URL to direct the user to.
        \item contentLabel: The bold title of the item, this is shown before the content text.
        \item contentMode: A special setting that depends on the item in particular. For links this will be used to describe the type of link (internal, external, internal download, external download).
        \item internal: Determines if the item should be viewable by the public, or just internal users. A value of 1 is only viewable by internal users, while a value of 0 is viewable by everyone.
        \item sourceId: The ID of the source that this item is referencing.
    \end{itemize}
\end{itemize}
\begin{lstlisting}[caption=Example Request Body]
{ 
  headerId: 2,
  cardType: 0,
  title: "Best Practices",
  items: [
   {
     cardId: 1,
     indentation: 0,
     iconType: 16,
     contentText: "An informational page with analysis tools",
     contentUrl: "https://www.bpa.gov/EE/Sectors/Industrial/Pages/Co",
     contentLabel: "Bonneville Power Administration",
     contentMode: 0,
     internal: 0,
     sourceId: 2
   }
  ]
}
\end{lstlisting}
\begin{itemize}
  \item insertId: The ID of the newly created card.
\end{itemize}
\begin{lstlisting}[caption=Example Response]
{ 
  insertId: 10
}
\end{lstlisting}

\noindent
\textbf{\textcolor{BlueGreen}{PATCH} api/cards/:cardId/move/:direction/:mode} \\
Changes the selected card's position relative to other cards when displayed. If we are moving an unpublished card, it will move the card relative to all cards (excluding its published version). If we are moving a published card it will move relative to published cards (skipping over unpublished cards). Only editors or admins can move an unpublished card. Only admins can move a published card.
\begin{itemize}
    \item cardId: The ID of the card to move.
    \item direction: A value of 1 moves the card up one row. A value of 0 moves the card down one row.
    \item mode: States what type of card we want to move. A value of 0 represents an unpublished card. A value of 1 represents a published card.
\end{itemize}
\begin{lstlisting}[caption=Example Response]
{ 
  cardId: 1
}
\end{lstlisting}

\subsection{Category Endpoints}


\noindent
\textbf{\textcolor{RoyalBlue}{GET} api/categories/all} \\
Gets all of the catogories and their respective pages. Users without an account, or external users will get all published categories and pages that are not internal. Internal users, editors, and admins will get all categories and pages.
\begin{itemize}
    \item categoryId: The ID of the category.
    \item created: The date that the category was created.
    \item description: A general description of the category.
    \item internal: Whether the category is viewable by the public (value of 0) or just by internal users (value of 1).
    \item pluralName: The plural name of the category.
    \item singleName: The singular name of the category.
    \item userId: The ID of the user who created the category.
    \item pages: The list of pages that belong to the category.
    \begin{itemize}
        \item approved: Whether this page is published and viewable in view mode.
        \item description: The description of the page.
        \item internal: Whether the page is viewable by the public (value of 0) or just by internal users (value of 1).
        \item name: The name of the page.
        \item pageId: The ID of the page.
        \item pageType: The category ID that the page belongs to.
    \end{itemize}
\end{itemize}
\begin{lstlisting}[caption=Example Response]

  categories: [

    \item description: Text that describes the general subject of the page.
    \item imageUrl: The URL for the image shown at the top of the page.
    \item created: The time that the page was created, last updated, or last published (whichever was most recent).
    \item userId: The ID of the user who created or last updated the page (whichever was most recent).
    \item approved: Lets us know if the page is published (1) or unpublished (0).
    \item internal: Determines if the page should be viewable by the public, or just internal users. A value of 1 is only viewable by internal users, while a value of 0 is viewable by everyone.
  \end{itemize}
  \item headers: Headers that were published or deleted within the date range.
  \begin{itemize}
    \item historyId: The ID of this history record.
    \item removed: If this history record is noting the removal of the header, then this value will be 1. If this history record is signifying that the header was published, then the value will be 0.
    \item oldVersion: The previous version of this header. Has most of the same attributes as this header. Used for comparing changes on a report.
    \item headerId: The ID of the header.
    \item pageId: The ID of the page that this header belongs to.
    \item orderIndex: The order that the headers should be displayed in. A lower value means the header is displayed before a header with a higher value.
    \item title: The title of the header.
    \item internal: Determines if the header should be viewable by the public, or just internal users. A value of 1 is only viewable by internal users, while a value of 0 is viewable by everyone.
    \item created: The time that the header was created, last updated, or last published (whichever was most recent).
    \item userId: The ID of the user who created or last updated the header (whichever was most recent).
    \item approved: Lets us know if the page is published (1) or unpublished (0).
  \end{itemize}
  \item cards: Cards that were published or deleted within the date range.
  \begin{itemize}
    \item historyId: The ID of this history record.
    \item removed: If this history record is noting the removal of the page, then this value will be 1. If this history record is signifying that the page was published, then the value will be 0.
    \item oldVersion: The previous version of this card. Has most of the same attributes as this card. Used for comparing changes on a report.
    \item cardId: The ID of the card.
    \item HeaderId: The ID of the header that this card belongs to.
    \item cardType: The type of card to create. Examples include: default card, internal card, thumbnail gallery, internal thumbnail gallery, and more.
    \item title: The title of the card.
    \item created: The time that the card was created, last updated, or last published (whichever was most recent).
    \item userId: The ID of the user who created or last updated the card (whichever was most recent).
    \item approved: Lets us know if the card is published (1) or unpublished (0).
    \item orderIndex: The order that the cards should be displayed in. A lower value means the card is displayed before a card with a higher value.
    \item items: The items that belong to this card.
    \begin{itemize}
        \item itemId: The ID of the item.
        \item cardId: The ID of the card that this item belongs to.
        \item indentation: The level of indentation (0 is none, 3 is max).
        \item iconType: The ID of the icon that is displayed at the start of the item.
        \item contentText: The main body of text for the item.
        \item contentUrl: The URL of the item. For graphic items this will be the URL of the image to display, for link items this will be the URL to direct the user to.
        \item contentLabel: The bold title of the item, this is shown before the content text.
        \item contentMode: A special setting that depends on the item in particular. For links this will be used to describe the type of link (internal, external, internal download, external download).
        \item internal: Determines if the item belongs to a published (1) or unpublished (0) version of the card.
        \item iconType: The ID of the icon to use with this item.
        \item typeName: The Font Awesome name of the icon that is used with this item.
        \item typeKeyWord: The name displayed when a user hovers over the icon.
        \item color: The hex color code to use for the icon.
        \item sourceId: The ID of the source that this item is referencing.
    \end{itemize}
  \end{itemize}
\end{itemize}
